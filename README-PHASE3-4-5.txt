# PageGuard — Combined Phase 3 + Phase 4 + Phase 5 package

This package combines:
- Phase 3: GitHub Actions checks (`npm test`, TypeScript check, Vite production build)
- Phase 4: Capacitor dependencies and Android platform generation
- Phase 5: Android debug APK build and upload as a GitHub Actions artifact

## Important: how to apply this package

The repository's current `scripts/extract_zips.py` intentionally skips `.github/workflows/` as a protected path. Therefore, uploading this ZIP into `incoming-zips/` will extract the ordinary files but will NOT install the CI workflow.

To install every file from this package, extract it on your device/computer and upload the files into the repository root while preserving paths:
- `package.json` -> repository root (replace existing)
- `capacitor.config.ts` -> repository root (replace existing)
- `.github/workflows/ci-android.yml` -> `.github/workflows/ci-android.yml` (create this file directly in GitHub; do not put it through the ZIP extractor)

After these files are committed to `main`, GitHub Actions should run. Open the Actions tab and select "PageGuard - Test, Build and Android APK". If tests/build succeed, download the `PageGuard-debug-apk` artifact from the successful run and extract `app-debug.apk`.

## Notes and safety

- This produces a debug APK for testing, not a Play Store-signed release.
- The Android platform folder is generated by Capacitor during CI, so it does not need to be included in this ZIP.
- The workflow does not enable Facebook video deletion. PageGuard remains read-only.
- The app still needs device testing and Meta API/security review before production use.
- `npm install` is used because the repository currently has no committed package-lock.json. Commit a lockfile later and change CI to `npm ci` for reproducible installs.
